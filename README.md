# Bhasha — Research Project Website

Academic information website for the **Bhasha** research project.
Built with plain **HTML + CSS only** (no JavaScript), as required by the course guidelines.

## Files

```
bhasha-website/
├── index.html          Home — abstract, headline results, components
├── domain.html         Literature survey, gap, problem, objectives, methodology, technologies, results
├── milestones.html     Assessment timeline (drop-down per milestone) with dates and marks
├── documents.html      Links to all documents (Google Drive)
├── presentations.html  Links to all slide decks + embedded viewer
├── about.html          Supervisors, members, achievements
├── contact.html        Contact details, mailto form, map
├── styles.css          Shared styles (colours taken from the Bhasha logo)
└── images/
    ├── bhasha-logo.webp
    └── favicon.png
```
